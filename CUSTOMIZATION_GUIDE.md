## 🎨 Optional Customizations

### Change Theme Colors
The current theme is "tokyonight". You can change it by replacing `theme=tokyonight` with other themes:
- `dark`, `radical`, `merko`, `gruvbox`, `dracula`, `monokai`, `synthwave`, etc.

Visit [GitHub Readme Stats Themes](https://github.com/anuraghazra/github-readme-stats/blob/master/themes/README.md) for more options.

### Contribution Snake Animation (Lines 106-110)
The snake animation requires a GitHub Action to generate. To enable it:
1. Create a `.github/workflows/snake.yml` file
2. Add the snake generation workflow
3. The snake will appear after the first workflow run

## 🚀 After Customization

